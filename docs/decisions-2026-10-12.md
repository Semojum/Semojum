# 10월 12일 회의 반영

근거: [10.12. 정기 회의](https://app.notion.com/p/3f743813bc2e80b6b6f3da169ce1b1a2). 2026-10-14에 본문과 회의 요약을 확인했다. 개발 관련 결정만 정리한다. 회의 당시의 예정 일정은 구현 완료의 근거로 사용하지 않는다.

| 회의 결정 | 앱 반영과 검증 경계 |
|---|---|
| 분권 기준 옵션을 없애고 범위 지정 저장으로 통합 | 별도 분권 옵션을 만들지 않는다. F-07-03의 원본 쪽/점자 면 기준 BRF·점자 TXT 내보내기를 연결했다. 묵자 TXT는 원본 쪽 기준이다. |
| AI 재변환 기능 제외, 변환 실패 쪽 표기 유지 | AI 재변환 API/버튼을 추가하지 않는다. 서버가 알려 준 쪽별 실패 상태는 보존한다. 실패 쪽 원본 표시와 탐색 UI는 별도 구현 항목이다. |
| 조판·다운로드를 BE에서 FE로 이관 | 앱이 로컬 엔진의 `brf` 명령으로 조판하고 파일을 만든다. 현재 서버 저장은 최신 V3.1의 쪽별 텍스트·점자·메모 저장 계약을 따른다. 회의 요약의 ‘최종 파일만 서버 저장’을 근거로 없는 파일 업로드 API를 가정하지 않는다. |
| 줄바꿈 불가능 위치 인덱스 제공 | 실제 엔진의 `breaks`를 보존하고 조판에 전달한다. 직접 고친 점자에는 이전 인덱스를 재사용하지 않는다. 직접 수정 후 경계 재계산 규칙과 큰 문서에서의 입력 지연은 QA가 필요하다. |
| 실시간 우측 점역 표시 유지, QA 후 UX 결정 | 입력이 멈춘 뒤 450ms에 로컬 재점역하는 현재 동작은 구현 기본값이다. 회의에서 이 수치를 확정한 것은 아니며 IME·반복 입력·긴 블록 지연 검증 후 조정한다. |
| 삽입 메뉴 태깅 명세와 텍스트 항목의 점역 API 분리 | 실제 엔진 태그 목록을 기준으로 삽입한다. 꼬리말은 `header_footer`와 `force_roman`으로 별도 점역한다. 전체 삽입 메뉴 UI는 미완료다. |

‘AI 재변환 제외’는 원본 문서를 서버 AI로 다시 처리하는 기능에 해당한다. 편집한 묵자의 로컬 재점역과 로컬 엔진 장애 후 재시도는 편집 기능에 필요하므로 유지한다.

이후 이 대화에서 확정한 저장 정책이 우선한다. 자동 저장은 없으며 Ctrl+S·명시적 저장만 로컬과 서버에 반영한다. BE 결함은 앱에서 임의 우회하거나 BE를 수정하지 않고 [수정 제안](backend-save-review.md)에 남긴다.

범위 저장의 추가 결정: 사용자는 ‘선택한 페이지의 점자 그대로 저장’을 선택했다. 점자 TXT는 조판 결과를 유니코드 점자로 기록하고 쪽번호·꼬리말·빈 줄·면 경계를 보존한다. 점자 면 범위는 표지를 포함한 출력 순서(1부터)이며 인쇄된 번호와 다를 수 있다는 안내를 표시한다. 기존 번호를 유지하려면 점자 면 범위를 사용한다. 원본 쪽 범위는 선택한 쪽만 별도 조판하므로 점자 면 번호는 현재 판면의 시작 번호부터 시작한다.
