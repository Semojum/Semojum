# 구현 상태와 남은 결정

2026-10-14 기준. ‘연결’은 클라이언트 코드가 연결되었다는 뜻이며 운영 환경에서 성공했다는 뜻이 아니다.

## 확정된 결정

- 자동 저장 없음. Ctrl+S/명시적 저장만 로컬과 서버에 반영한다.
- `.smj`는 버전 있는 ZIP이며 원본·텍스트·점자·메모·설정을 포함한다.
- 로컬 엔진은 Semojum/braille v3.4.17 실제 코드 기준. 가이드와 차이는 별도 문서에 기록한다.
- 새 문서가 서버 작업이 되는 시점은 미정이다. 사용자는 이후 판단할 수 있도록 문서화하도록 요청했다.
- 새 블록의 서버 동기화 규칙은 BE 코드까지 조사했다. 사용자 결정에 따라 BE는 변경하지 않고 앱과 수정 제안 문서만 작성한다. 현재 결함과 필요한 계약은 backend-save-review.md에 있다.

엔진 계약·오류 복구, 인증, ZIP round-trip과 무결성, JSON 매핑/업로드/부분 저장을 자동 검사한다. 네트워크 API 검사는 가짜 HTTP 응답을 이용한다. 실제 엔진은 v3.4.17 Python 런타임과 패키징된 실행 파일로 각각 검사한다. Windows CI에서 WPF 창·편집 버퍼·SMJ 복원도 검증한다. 운영 서버 로그인·유료 변환은 실행하지 않았다.

최근 파일/폴더의 근거는 [F-01-03 최근 문서](https://app.notion.com/p/3f143813bc2e81b1b506d20e80c35b2f), [F-08-01 작업 폴더](https://app.notion.com/p/3f143813bc2e8127b6bac0be2d331fde)다. 최근 파일 10개 제한·중복 제거·설정 재시작 복원, 폴더 확장자 필터·하위 폴더·삭제 반영, 저장된 커서 복원을 검사한다. 단일 문서 창에서 같은 파일을 다시 선택해도 미저장 내용은 다시 읽어 덮어쓰지 않는다. 여러 문서 탭은 별도 미구현 상태다.

## 추가로 확인할 내용

1. 새 문서 빈 화면 → 서버 작업 생성의 사용자 동작과 AI 과금 시점.
2. BE의 첫 점자 저장과 새 블록 id 매핑 결함 수정 후 연동 검증. BE 변경은 이번 요청 범위에서 제외되었다.
3. Figma 연결 권한. 화면 구현 완료 여부는 디자인을 읽고 비교한 뒤 판단한다.
4. 표의 `contents` 편집을 `table_source`에 반영하는 규칙. 현재 엔진의 table 명령은 table_source를 사용한다.
5. 시각 자료 초안 label과 계정 visualDescriptions 이름의 대응. BE도 아직 AI 팀과 미합의라고 명시한다.
6. 조판 editScope=page를 저장·복원할 수 있으나 실제 면별 조판 override 표현은 현재 문서 모델에 없다.

기능정의서 전체 완료나 배포 준비 완료로 표시하지 않는다. 데이터가 사라지거나 유료 요청이 의도와 다르게 발생할 수 있는 미정 동작은 추측으로 채우지 않는다.
