# 데스크톱 편집기 구현 상태

2026-10-19 기준. [Service 기획](https://app.notion.com/p/3a643813bc2e801aa2b9eaf48dde8f2e)의 최신 ‘세부 기능’을 우선한다. 직접 확정한 예외와 충돌은 [우선순위 기록](service-priority.md)에 있다. **전체 기획 구현 완료 또는 배포 승인 상태는 아니다.**

## 이번 범위

사용자 확정: 현재 데스크톱 편집기를 우선한다. 관리자 웹 대시보드와 서버 폴더·휴지통은 후속 범위다. BE를 변경하지 않고 수정안을 문서화한다. 계정 화면·작업 이력 조회·로컬 작업 폴더는 편집기의 사용 흐름으로 유지한다.

자동 저장은 없다. Ctrl+S·명시적 저장만 .smj와 서버 저장을 요청한다. 실제 엔진은 Semojum/braille v3.4.24다. 미확정 6점키 프리셋은 만들지 않고 사용자 지정 키를 제공한다. 문의 주소는 contact-semojum@gmail.com, 운영 기관명은 등록 전이다.

## 데스크톱 P0 잔여 항목

1. **조판과 동일한 모눈 편집**: 현재 모눈은 줄·칸 좌표를 유지하고 클릭하면 공유 편집기로 이동한다. 실제 breaks·페이지행·변경선·머리말을 반영한 최종 배치는 BRF 복원 미리보기에서 검증한다. 완성된 면 안에서 선택·직접 편집·블록 드래그를 연결하는 작업이 남았다.
2. **조판 옵션의 효과**: 엔진 JSON page_row_pages는 odd/every만 받는다. none은 번호 숨김으로 연결하지만 본문 공간까지 회수하지 못한다. show_change_line·면별 editScope의 효과도 현 JSON 계약에서 보장되지 않는다. 전환선 개별 설정은 비활성화하고, 미지원 언어·공백 옵션은 설정 화면에 적용 한계를 표시한다. [엔진 차이](engine-contract.md) 참조.
3. **추가 계약이 필요한 오류 흐름**: 실패 쪽 AI 재시도, 암호 PDF 암호 전달, OCR 신뢰도/미지원 글자 감지, 영어 문서·혼용·공백 정책은 계약 또는 응답 근거가 더 필요하다. 임의 재업로드로 추가 과금을 일으키지 않는다.
4. **사용 환경 검사**: 한국어 IME, 키보드 롤오버, 스크린 리더, 다중 모니터/DPI, 큰 원고 성능, 물리 프린터, 실제 배포 업데이트는 장비/운영 환경 검증이 남았다.

## 백엔드 결함과 후속 범위

빈 문서 생성 API는 존재한다. 핵심 저장 결함은 첫 점자와 신규 블록의 ID 매칭이다. [현재 BE 근거와 수정안](backend-save-review.md)에 첫 저장·중복 문장·병합/분할·부분 실패 검증 조건을 기록했다. 앱은 로컬 파일을 먼저 보존하고 서버 실패를 별도로 표시한다.

후속: 관리자 웹(계정/기관/크레딧/공지 운영), 서버 폴더·휴지통(이동/복원/영구 삭제/권한/보관 정책). 초안 약관·파일처리방침은 시행일과 운영 값 확인 없이 확정 정책으로 게시하지 않는다.
