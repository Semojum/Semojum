# 세모점 작업 파일 v1

2026-10-14 사용자 승인: 확장자 `.smj`, 버전 있는 ZIP. 자동 저장은 하지 않는다. Ctrl+S 또는 명시적 저장 때 로컬 파일과 서버 저장을 실행한다. 쪽 이동·종료 자체는 저장하지 않으며 미저장 변경이 있으면 저장/버리기/취소를 선택한다.

`manifest.json`의 `format`은 `semojum-work`, `version`은 1이다. 블록의 원문·점자·서버 id·타입·표 구조·초안·음절 경계·수동 수정 표시·줄 메모·텍스트/점자 커서 위치, 조판·점역 옵션·꼬리말, 현재 블록, 작업 id·소유 계정 id·작업 상태, 원본 쪽 정보와 원본 파일 목록을 담는다. 인증 토큰과 비밀번호는 저장하지 않는다. 커서 필드가 없는 초기 v1 파일은 각 블록 시작 위치로 연다. 커서 이동만으로 파일을 자동 저장하거나 미저장 변경 표시를 켜지 않는다.

원본 바이트는 `originals/0000` 형태의 엔트리에 담고 manifest에는 원래 파일명, 길이, SHA-256을 기록한다. URL이 만료되어도 읽을 수 있도록 다운로드된 원본 미리보기도 보존한다. ZIP 엔트리를 디스크 경로로 풀지 않는다. 중복 엔트리·누락 항목·해시 불일치·알 수 없는 버전은 열지 않는다. 확장 크기 512 MiB, manifest 64 MiB 제한이 있다.

저장 시 편집 데이터를 스냅샷으로 복사한 후 같은 폴더의 임시 파일에 쓰고 flush 후 교체한다. 취소나 쓰기 실패 때 기존 파일은 유지한다. 저장 도중의 추가 편집은 저장 완료로 간주하지 않는다. 서버 저장의 부분 실패와 로컬 저장 성공은 따로 알린다.

서버 save 응답은 새 블록 id를 돌려주지 않는다. 새 블록과 점자의 매칭·id 회수 규칙을 확인하기 전에는 서버가 이미 발급한 id가 있는 블록만 서버에 저장한다. 로컬 초안은 `.smj`로 보존할 수 있다. 사용자 승인 없이 저장 작업을 AI 변환이나 유료 작업 생성으로 바꾸지 않는다.

기존 `.mock.smi`는 읽어서 `.smj`로 옮길 수 있는 레거시 목업 형식이며 배포용 규격이 아니다.
