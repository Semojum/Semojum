이 문서는 [QA 4차 기록](qa4-2026-10-27.md) 이후의 최신 상태다. 전체 설계 구현 또는 모든 화면의 픽셀 일치가 완료되었다는 뜻은 아니다. [남은 작업](remaining-work.md)과 [54개 화면 비교](visual-review/README.md)를 함께 본다.

## 반영 범위

- UI_1020의 설계 59개를 확보하고, 대응 가능한 화면 54개를 실제 WPF에서 캡처했다. 원본은 [Figma](https://www.figma.com/design/unGdqbrKjhxhi8t3co9VOt/Semojum-UI?node-id=1-3), 상세 조회와 비교에 사용한 복제본은 [화면 대조용 복제](https://www.figma.com/design/GTexdXykSRobKPUCDjqnxB?node-id=1-2)다.
- 파일·편집·보기·삽입·설정·정보 메뉴의 표시 항목과 순서를 맞췄다. 팝업 너비는 모두 222 DIP, 높이는 차례대로 169/250/379/355/193/178 DIP다. 기존 추가 기능은 도움말의 ‘메뉴별 기능 → 추가 도구’로 접근하며, 6점 입력은 F6으로 전환한다.
- 보기의 도구 모음·상태 표시줄·메모·검토 표시와 모든 패널 복원을 연결했다. 보기 변경과 창 복원은 원문·점자·미저장 상태를 바꾸지 않는다.
- 메인 화면의 패널 경계, 텍스트 시작점 52 DIP, 현재 줄 배경의 왼쪽 12 DIP, 글자 기준선, 상태줄의 구분선을 조정했다. TXT는 텍스트:점자 60:40을 사용한다.
- Inter Regular/SemiBold, Noto Sans KR Regular/SemiBold, Roboto Mono Regular를 라이선스와 함께 배포한다. WPF 글꼴 경로가 Windows 기본 글꼴로 대체되던 문제를 수정했고, 실제 그려진 글자의 폰트 파일을 검사한다. 사용자가 별도로 고른 편집 글꼴은 유지한다.
- 도움말 트리·탭·제목 간격, 게시글의 제목·메타데이터·구분선·첨부·답변, 수식 입력 글꼴과 기호 선택 표시를 조정했다. 기존 메모·대체 초안·양식·경고 창의 Figma 스타일과 실제 동작도 포함한다.

## 승인된 설계 예외

Figma의 마지막 입력 행이 하단 버튼과 겹치는 두 창은 사용자의 선택에 따라 **행 간격을 유지하고 창 높이만 늘렸다.** 범위 지정 저장은 520×200에서 **520×240**, 페이지 설정은 480×250에서 **480×280**으로 조정했다. 따라서 대응 54개 중 52개는 참조와 전체 크기가 같고, 두 창은 의도적으로 다르다. 같은 크기가 픽셀 일치를 의미하지는 않는다.

기존 실서버 고유 검사 66개는 이전 실행의 증거다. 승인된 비밀글은 등록·수정·첨부 검증 후 삭제했고 삭제 후 404와 목록 제거를 확인했다. 이번 화면 캡처는 별도 로컬 테스트 데이터이며 운영 게시글을 새로 만들지 않았다. 한글 문장·공백·마지막 조합 글자를 같은 창의 다른 입력칸으로 포커스 이동하며 보존하는 실키보드 검증도 이전에 통과했다.

## 비교 해석

문서 본문·선택·줄/쪽 위치·점역 결과·계정/사용량은 실제 모델 또는 캡처용 테스트 데이터이므로 Figma 예시 데이터와 다르다. 수식은 실제 2차원 수식 렌더러를 사용한다. 유지·덮어쓰기·취소처럼 기존 편집 내용을 보호하는 선택과 실제 오류 안내는 설계 예시의 짧은 문구로 대체하지 않았다.

현재 남은 시각 차이에는 양식 고르기의 스크롤바, 도움말 탭 구분자, 일부 긴 안내문의 줄바꿈·버튼 배치가 있다. 운영자 화면과 일부 사전 안내 흐름 5개는 대응 캡처가 없다. 배율별 표현과 외부 앱으로 포커스를 옮기는 한글 입력 등은 별도 검증이 남았다. 세부 완료 조건은 [남은 작업](remaining-work.md)에 기록한다.
