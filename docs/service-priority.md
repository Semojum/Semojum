# 서비스 기획 우선 적용

확인일: 2026-10-19. 사용자가 지정한 [Service](https://app.notion.com/p/3a643813bc2e801aa2b9eaf48dde8f2e)를 구현의 최우선 문서로 사용한다.

## 기준 순서

1. 대화에서 사용자가 직접 확정한 결정
2. Service DB의 서비스 기획. 같은 항목에서는 최신 수정본인 [세부 기능](https://app.notion.com/p/3ef43813bc2e802f9ea2c8a7858b9083) (2026-10-13)을 우선한다.
3. Service DB의 원고지형 에디터(8월 17일), 조판·다운로드(8월 5일), 디렉토리(8월 4일), 사용설명서(8월 24일). 최신 세부 기능에서 다루지 않는 동작을 보충한다.
4. 기능정의서 V2, 회의록, Figma는 구체적인 화면·상호작용의 참고 자료다.
5. API와 실제 엔진 코드는 연동 가능 여부의 근거다. 기획과 다른 경우 기획을 삭제하거나 성공으로 가장하지 않고, 앱에서 가능한 부분과 서버·엔진 변경이 필요한 부분을 나눈다.

## 직접 결정되어 유지하는 사항

- 자동 저장 없음. Ctrl+S와 최종 저장에서만 로컬 `.smj`와 서버 저장을 시도한다. 닫기·쪽 이동·업데이트가 임의로 문서를 저장하지 않는다.
- `.smj`는 버전 있는 ZIP으로 원본·텍스트·점자·메모·옵션을 보존한다.
- 선택한 점자 면의 TXT는 조판된 점자를 그대로 내보낸다.
- 실제 점역 엔진을 사용하고 문서와의 차이는 기록한다.
- 백엔드 저장소는 수정하지 않는다. 저장 결함은 수정 제안 문서에 남긴다.
- 6점키는 사용자 지정부터 제공한다. 1·2·3단의 미확정 키 배열은 만들어 내지 않는다.
- 문의 주소는 `contact-semojum@gmail.com`. 운영 기관명은 확정 전이다.
- 이번 구현은 데스크톱 편집기 우선이다. 관리자 웹 대시보드와 서버 폴더·휴지통은 후속 범위로 문서화한다(2026-10-19 사용자 확정).

## 기획서 간 충돌 처리

| 항목 | 적용 기준 |
|---|---|
| Ctrl+Enter | 최신 세부 기능의 쪽바꿈. 새 블록 추가는 별도 메뉴 |
| 화면 | 최신 세부 기능의 원본·텍스트·점자 3패널. TXT·새 문서는 2패널 |
| 점자 표시 | 원고지형 기획의 칸 수 불변, 실제 줄바꿈 보존, 면 경계·줄 번호, 블록과 원본 연결 |
| 편집 키 | 최신 문서의 Enter 줄바꿈, Ctrl+A 한 번 블록·두 번 쪽. 오래된 HTML의 Enter 확정보다 우선 |
| 문맥 메뉴 | 최신 세부 기능의 줄 우클릭 메뉴. 오래된 HTML의 우클릭 없음보다 우선 |
| 줄바꿈 옵션 | 최신 세부 기능의 음절·어절 설정. 오래된 조판 가이드의 음절 고정은 초기 PoC 범위 |
| 페이지행 | 최신 기본값 홀수 면. 8월 5일 가이드의 매면 고정보다 우선 |
| HWPX | 최신 세부 기능에서 지원. 8월 사용설명서의 미지원 문구는 과거 상태 |
| 저장 | 사용자 결정 우선. 세부 기능 내부에도 자동 저장과 중간 저장 없음이 함께 있어 자동 저장을 도입하지 않음 |
| 연락처 | 직접 전달받은 Gmail 주소 우선. 8월 약관 초안의 주소로 바꾸지 않음 |
| 약관·파일처리방침 | 시행일·사업자·보관 기간 등 미확정 값이 있는 초안. 확정된 법률 고지로 재게시하지 않음 |

## P0 구현·검증의 우선순위

편집 화면과 판면 → 선택·편집·Undo → 점역·수식·메모·대체 초안 → 조판·범위 저장 → 옵션·양식 → 계정·도움말·게시판 → 오류 복구 순으로 확인한다. P1(출력 최적화, 프린터, 색상 등)이 P0 검증을 밀어내지 않게 한다.

## 앱만으로 완료할 수 없는 계약

- 새 텍스트 블록과 첫 점자 블록의 ID 연결: 현재 BE 저장 구현의 결함. `backend-save-review.md`에 근거와 수정안을 기록한다.
- Service DB의 디렉토리와 관리자 웹 콘솔은 별도 서버 계약·권한이 필요하다. 로컬 작업 폴더를 서버 폴더·휴지통 구현 완료로 취급하지 않는다.
- 작업 취소는 `POST /api/jobs/{jobId}/cancel`로 연결했다. 진행 중인 쪽은 서버가 마무리하고 최종 상태를 받는다. 실패한 쪽의 사용자 AI 재시도·OCR 감지·PDF 암호 전달은 별도 계약이 필요하다. 로그인 잠금 정보는 서버 응답을 표시하며 횟수·기간을 클라이언트에서 만들어 내지 않는다.
- 실제 엔진이 받지 않는 조판·언어 옵션은 `engine-contract.md`에 기록한다. 화면에서 값을 보존하는 것과 실제 점역에 적용되는 것을 구분한다.

이 문서는 우선순위와 충돌 해석의 기록이다. 모든 기능의 완료 선언이 아니다.
