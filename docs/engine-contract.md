# 로컬 점역 엔진 계약과 설계 차이

확인일: 2026-10-19. 서비스 기획이 요구사항의 기준이며, 사용자 결정에 따라 어댑터는 **실제 엔진 코드**를 사용한다. 지원되지 않는 요구를 자체 점역 규칙으로 추측하지 않는다.

기준: [Semojum/braille v3.4.24, 976b2048](https://github.com/Semojum/braille/tree/976b2048d1a1ad0b31a869001f80f9fa260b93af). `semojum_braille/sidecar.py`, `assist.py`, `docs/sidecar.md`를 확인했다. V3.4.17에 대한 이전 기록은 현재 어댑터의 계약이 아니다.

| 항목 | 실제 계약과 앱 처리 |
|---|---|
| 급수 | `korean_grade`, `english_grade` 정수 1/2. 한글·영문 급수 옵션 전달 |
| 선택지 | `split_choices` 지원. 한 줄 하나/짧으면 합치기 전달 |
| 표 | `translate`가 `<!표>` 구조를 받으며 초안·render_mode를 반환. 예전 `table_source`는 별도 table 명령 경로 유지. 앱의 표 편집 창은 셀→태그 구조로 저장 |
| 수식 | `<!수식>`을 감싸서 전달. 엔진이 BAD_LATEX·TOO_LONG을 반환할 수 있음 |
| 원문 길이 | 태그를 뺀 묵자 1,000자 제한. 평문 TXT는 유니코드 경계를 보존해 나눔. 태그 문서는 중첩 구조를 임의로 분리하지 않으며 엔진 길이 오류를 표시 |
| 태그 | `unknown_tags`와 dropped/blocked를 실제 응답대로 보존 |
| 기호 | `symbols` 명령으로 엔진 제공 기호 표 사용 |
| 조판 | `build_brf` + `job.sources`, `opts`, `footer`, `header`. 결과 BRF와 replaced를 검사하고 `read_brf`로 점자 면 복원 |
| 머리말·꼬리말 | 엔진은 전역 값과 면별 `headers`/`footers`를 지원. 앱은 기본 꼬리말과 시작·끝 면 범위, 끝까지 적용, 빈 내용으로 숨기기를 전달. 머리말은 아직 마지막 값을 전역 적용하므로 삽입 위치부터 변경은 미완료 |
| 페이지행 | JSON 어댑터는 `odd`/`every`만 허용. 내부 Options의 `even`/`none`과 `show_change_line`은 JSON 어댑터에 노출되지 않음 |
| 출력 안 함 | 현재 앱은 번호 표시를 끄지만 페이지행의 자리까지 제거되지는 않을 수 있음. 완전한 페이지행 제거는 엔진 어댑터 계약 변경 필요 |
| 꼬리말 정렬 | 실제 `assist.py`는 left/center/right를 모두 지원. 앱은 파일 전체 정렬 3가지를 제공. 범위마다 다른 정렬은 미지원 |
| 꼬리말 출력 범위 | 출력 안 함/홀수 면/전체 및 개별 범위. 엔진이 페이지행을 만드는 면에만 출력되므로 페이지행 홀수+꼬리말 전체일 때 짝수 면에는 출력되지 않음. 꼬리말 범위는 `.smj` 전용이며 서버 save는 기본 텍스트만 받음 |
| 언어·공백 | 영어 문서 규정, 한영 혼용, 연속 공백 정책은 옵션을 보존하나 실제 translate 계약에 대응 필드 없음. `force_roman`은 일반 영어 문서 설정과 같은 의미가 아님 |
| 검수 등급 | grade는 확인 우선순위이며 정확도 또는 검수 완료 판정이 아님 |

## 실행과 오류 처리

UTF-8 JSONL 요청/응답의 id, 시작 ping의 protocol=1을 검사한다. stderr는 별도로 비우고 내용을 저장하지 않는다. 취소·시간 초과·응답 오류 후 프로세스를 정리한다. 실패 때 샘플 점자를 대신 반환하지 않는다.

0.4초 내 응답이 없으면 점자 입력을 잠그고 지연 상태를 알린다. 원문 편집과 명시적 저장은 유지한다. 엔진의 최초 시작을 허용하기 위해 요청은 제한 시간 내에서 계속 기다리며, 현재 요청의 응답이 오면 점자 잠금을 해제한다. 원문·메타데이터·수동 점자·요청 세대가 바뀐 응답은 적용하지 않는다.

모눈 보기는 블록 원문과 편집 좌표를 연결하는 근사 표시다. 삽입된 표시용 줄바꿈과 빈칸은 저장 문자열에 쓰지 않는다. 최종 조판·페이지행·꼬리말 검수에는 실제 엔진 BRF를 복원하는 ‘점자 면 미리보기’를 사용한다. 두 화면이 완전히 같은 편집 판면이라고 주장하지 않는다.

## 검증과 미검증 범위

실제 Python v3.4.24로 급수, 표 초안, 알 수 없는 태그, 기호, 검수 순서, BRF 생성·복원을 검사한다. Windows 패키징 엔진도 별도 CI로 검사한다. 전체 점역 정확도·모든 수식과 표·실제 점자 프린터의 물리 출력은 이 검사로 보증되지 않는다. 라이선스·NOTICE·third_party 고지는 배포물에 포함하고 kiwi는 번들하지 않는다.
