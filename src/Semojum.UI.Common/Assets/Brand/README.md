# 누리닷 로고

출처: 팀 공유 자료의 [로고 페이지](https://app.notion.com/p/40d43813bc2e800fb5aeee011ab11346), 2026-11-09 사용자 지정.

- `nuridot-logo.svg`: 페이지의 `nuridot_logo.svg` 원본. 로그인 화면의 전체 로고.
- `nuridot-symbol.svg`: 페이지의 `nuridot_symbol.svg` 원본. 편집기·분리 창·도움말 등의 제목 표시줄 심벌.
- `nuridot.ico`: 심벌 SVG를 비율 유지·투명 배경의 정사각형 중앙에 렌더링한 Windows 아이콘. 16, 24, 32, 48, 64, 128, 256px PNG 프레임을 포함하며 실행 파일과 창 아이콘에 사용합니다.

SVG는 원본 그대로 보존합니다. 만료되는 Notion 다운로드 주소는 저장하지 않습니다.
